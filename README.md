# Hotel Management System

A simple console-based Hotel Management System developed using Java.

## Features

- Add Customer
- View Customer Details
- View Available Rooms
- Book Room
- Check-In
- Check-Out
- Generate Bill
- Exit

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Scanner for user input

## Project Structure

- `Main.java` - Main program and menu
- `Customer.java` - Customer details
- `Room.java` - Room details and availability
- `Booking.java` - Booking and hotel operations

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code or any Java IDE.
3. Compile the Java files.
4. Run `Main.java`.
5. Follow the menu options displayed in the console.
